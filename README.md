# Paradigmas de Aprendizaje en IA

Sitio web pedagógico sobre los 9 paradigmas de aprendizaje en Inteligencia Artificial:
definiciones, explicaciones, diagramas propios, ejemplos didácticos y ejercicios interactivos.

## Temas
1. Aprendizaje supervisado
2. Aprendizaje no supervisado
3. Aprendizaje semisupervisado
4. Aprendizaje autosupervisado
5. Transfer Learning y Fine-tuning
6. Aprendizaje por refuerzo
7. Alineación mediante RLHF y RLAIF
8. Aprendizaje en contexto
9. Modelos del mundo (World Models)

## Stack
HTML, CSS y JavaScript puro. Sin build, sin dependencias. Se despliega como sitio estático.

## Ver localmente
    python3 -m http.server 8000

y abrir http://localhost:8000
